# HEATWATCH — Database Config

This directory holds configuration templates for database tooling.

## Files

| File | Purpose |
|---|---|
| `database.env.example` | Copy to `database.env` and fill real values for local development |

## Usage

```bash
cp database/config/database.env.example database/config/database.env
# Edit database.env with real credentials
```

Never commit `database.env` to version control.
